# Video 1 — diagram starters

20 frames, one per storyboard row, 1920×1080, in the brand diagram grammar.
Each frame exists as SVG (editable) and PNG (preview). contact-sheet.png shows all 20.

How to use
1. Import the SVGs into Figma (File → Import, or drag in). Each becomes an editable frame.
2. Replace fonts: the SVGs specify IBM Plex Sans / Mono; install both from Google Fonts before opening or Figma substitutes.
3. These are starting positions, not finished art. Adjust spacing, add the moving dots as separate layers for animation, and tune label sizes on a phone preview.
4. Motion rule from the brand sheet: only dots move along pipes. Everything else cuts in.
5. Fault red appears only in frames 15, 16, 17 and (one cell) 19. Keep it that way.

Frame → storyboard row mapping is 1:1. The grey title at top-left of each frame is the storyboard cue; delete it before export.
